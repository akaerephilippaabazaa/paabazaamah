# SURGICISS LTD — Static Website

This folder contains the static HTML version of the SURGICISS LTD website. The site keeps the existing page structure, styling, scripts and image assets while replacing PHP page templates with HTML pages where practical.

## Main sections

- Home
- Products
- Instrument Count Sheet Holders
- Software
- About
- Contact
- Request a Quote
- Request a Software Trial

The official SURGICISS LTD PNG logo is stored in `assets/images/` and is used throughout the site.

Open `index.html` to view the website locally.
